# 从HTTP错误码到领域错误

## 400：Bad Request

Handler：JSON/ID格式非法

Service：

- ErrInvalidTaskInput
- ErrInvalidEvidenceContent

Repo:

- ErrInvalidPageination
- ErrInvalidReference

## 401: Unauthorized

JWT Middleware:

- Token缺失或非法

Service：

- ErrInvalidCredentials

## 403：Forbidden

Service:

- ErrConversationForbidden

## 404：Not Found

Service:

- ErrProjectNotFound

Repo:

- ErrNotFound

GORM:

- ErrRecordNotFound

## 409 ：Conflit

Service:

- ErrprojectAlreadyExists  ----> Repo:ErrAlreadyExists----->ErrDuplicatedKey -----> MySQL:唯一键冲突
- ErrTaskVersionConflict ------>CAS更新0行
- ErrInvalidTaskTransition

- ErrTaskEvidenceRequired

## 500 :Internal Error

Handler:

- 未识别错误

Repo:

- ErrStorage

MySQL:

- SQL或连接故障

## 504:Gateway Timeout

Handler：

- DeadlineExceeded

Context:

- Timeout

## 各层错误的对照表

| HTTP | Handler 最终错误码         | Service 领域错误示例        | 下层来源                                |
| ---- | -------------------------- | --------------------------- | --------------------------------------- |
| 400  | `INVALID_ARGUMENT`         | `ErrInvalidTaskInput`       | 参数校验，或 Repository 无效引用        |
| 400  | `INVALID_EVIDENCE_CONTENT` | `ErrInvalidEvidenceContent` | 证据内容不符合规则                      |
| 401  | `INVALID_CREDENTIALS`      | `ErrInvalidCredentials`     | 用户不存在或密码错误                    |
| 403  | `FORBIDDEN`                | `ErrConversationForbidden`  | 会话所有者不匹配                        |
| 404  | `NOT_FOUND`                | `ErrProjectNotFound`        | `ErrNotFound` / `ErrRecordNotFound`     |
| 409  | `PROJECT_ALREADY_EXISTS`   | `ErrProjectAlreadyExists`   | `ErrAlreadyExists` / `ErrDuplicatedKey` |
| 409  | `VERSION_CONFLICT`         | `ErrTaskVersionConflict`    | CAS `RowsAffected = 0`                  |
| 409  | `INVALID_STATE_TRANSITION` | `ErrInvalidTaskTransition`  | 状态机校验失败                          |
| 409  | `PROJECT_ARCHIVED`         | `ErrTaskProjectArchived`    | 项目归档状态限制                        |
| 409  | `EVIDENCE_REQUIRED`        | `ErrTaskEvidenceRequired`   | 缺少已提交证据                          |
| 500  | `INTERNAL_ERROR`           | 未分类的内部错误            | `ErrStorage`、数据库错误等              |
| 504  | `DEADLINE_EXCEEDED`        | `context.DeadlineExceeded`  | 超时错误沿调用链返回                    |
